ADMIN PANEL UPDATE: LIVE BOARD + SAB KUCH LIVE
==============================================
Is update me koi naya rule deploy NAHI karna. Bas ye 2 kaam karo.

1) GITHUB PE 2 FILES BADLO
   Repo agentvoo.github.io > HippoAdminPanel > website
   Zip ke website folder se ye upload karke purani replace karo:
      style.css
      js/app.js
   (app.js repo ke js folder me hi jaani chahiye. firebase.js same hai, mat chhedo.)
   1-2 minute baad panel kholo aur Cmd+Shift+R dabao.

2) NAYA GAME UPDATE DAALO (zyada live data ke liye)
   Game ab har 1 minute pe data bhejta hai (pehle 3 minute), aur race ya full-screen ad
   ke ~10 second baad turant. Purane version wale players ka data 3 minute me aata rahega.

NAYA: LIVE BOARD (menu me Dashboard ke neeche)
  Ek screen jo khula chhod do (ya TV pe lagao, "TV mode" button = full screen):
    - Players online now: bada number + graph. Green = race me, blue = home screen.
      Graph board khulte hi banna shuru hota hai aur 30 minute tak dikhata hai.
    - Abhi kya kar rahe: gol chart, kitne race me / kitne menu me.
    - Aaj ke 5 counters: kitna khela (har second badhta hai), players, races, ads,
      naye players. Har ek ke neeche "kal ka kitna %" ki line.
    - Har minute kya hua: har minute ki races (blue) aur ads (gold) ke bars.
    - Kaunsi river pe race chal rahi, online players ke level, aaj ke ads type ke
      hisaab se, kis desh se khel rahe, kaunsa game version, aur "Abhi abhi" feed.
    - Har graph ke upar ek line likhi hai ki usse kya samajhna hai.
  Top players (Analytics): online player ka "Hours" ab har second badhta dikhta hai.

PANEL ME KYA LIVE HUA (pichhla update)
  Analytics
    - Live now: kaun abhi game me hai, kitne race me, kitne home pe. Har change turant.
    - Playing now list: naam, level, kaunsi river pe race, kitne second pehle dikha.
    - Live activity: jaise hi kisi player ka data aata hai, yahan dikhta hai
      (+5m played, +2 races, +1 ad).
    - Tiles (Played today, New, Races, Ads, Hours...): naya data aate hi 10 second ke andar update.
    - Top players: LIVE ranking. Koi aage badha to row chamakti hai aur upar/neeche ka arrow.
        All time / Today, Top 25 / 50 / 100, Most hours / ads / races / sessions / level.
        Last seen ab game ki heartbeat se (40 second wali), green dot = abhi online,
        "LIVE · racing CANYON GATES" jaisa dikhega.
        Naam ya ID se search, aur Export CSV (Excel me khulta hai).
    - Countries aur game versions: live.
    - Aaj ka graph bar bhi live.
    - Upar LIVE pill: internet gaya to RECONNECTING dikhega, wapas aate hi khud jud jayega.
  Dashboard     Online now, Support waiting add hue. Forms aur Last actions live.
  Players       Recently active list live (green dot = online). Player kholo to uska
                time, races, ads (type ke saath), sessions, country, version, first day,
                last report sab live dikhta hai.
  Activity Log  Live.
  Menu badges   Forms / Support ke number har minute khud update.

KITNE BHI PLAYERS HON
  Har live list me limit hai (live players 1000 tak list, top 100), aur bade totals
  Firebase server pe hi gine jaate hain. Isliye 100 players ho ya 10 lakh, panel utna hi
  tez chalega aur Firebase reads control me rahenge. 1000 se zyada online hon to
  "Live now" number server se ginti karke dikhata hai.
